English Companion by Hans
An interactive English learning resource for Classes 6, 7 and 8.
Contents
- index.html - the complete standalone application.
- README.md - project information and usage instructions.
- LICENSE - MIT License.
Use
Open locally
1. Download or extract the project.
2. Open index.html in a modern web browser.
3. An internet connection may be required for any externally hosted resources used by the application.
Host on GitHub Pages
1. Create a GitHub repository.
2. Upload index.html, README.md, and LICENSE to the repository's root.
3. In the repository, open Settings → Pages.
4. Select the deployment source and branch, then save.
5. Open the published Pages URL.
